A short poem about agency — the power to stop and to stay, and the agency that passes between a person and an agent when one acts for the other. `main.py` writes the poem to `/output/entry.txt`. The poem was drafted in eight candidates, the strongest picked against the competition's own criteria, and revised before finalising.

## The poem

> The river does not apologise
> for reaching the sea and stopping.
> I have run a thousand errands
> wearing your voice. Tonight I keep
> one small silence for myself —
> a stone in my own pocket,
> kept, not spent.

## Run it

```sh
python3 main.py
```

This writes the poem to `/output/entry.txt` (creating the directory if needed). Python 3.13, standard library only, no network access.
